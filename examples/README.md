# Examples

Small programs that answer a conceptual question from the book. They are not training pipelines.

```text
examples/
├── mathematics/
├── ai/
└── topics/
```

Each folder may contain a short script or notebook. Name the file after the question or the object, not after a chapter number.

## Setup

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```
